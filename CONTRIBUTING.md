# Contributing to MathBot

## Reporting bugs

Open an issue with steps to reproduce, expected vs actual output, and Python version.

## Suggesting features

Open an issue describing the use case and expected behavior.

## Pull requests

1. Fork the repo
2. Create a feature branch
3. Add tests if applicable
4. Submit PR with a clear description
